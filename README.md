# Path-Generator-Datapack
Automatically generate path block trails over frequently travelled areas

Additional Download URLS:
Modrinth:  https://modrinth.com/datapack/path-generator-datapack

Planet Minecraft:  https://www.planetminecraft.com/data-pack/path-generator-datapack/

The Path Generator Datapack is a mod free way to keep yourself from getting lost on your adventures in Minecraft!

Save your poor shovel, this datapack will auto generate walking trails, paths and roads for you as you walk around the world!

The more frequently you walk over an area, the more developed it becomes into an established path to guide you!

Customize!:
-Which blocks get turned into walking paths
-How large the path is when generated
-How frequently you have to walk for it to develop into a path

Supports!:
-Paths generated by Saddled horses, donkeys, mules, camels and pigs!

Why a datapack? Datapacks allow for a mod free experience with easy plug and play installation without any modloaders. This allows the datapack to work across multiple game versions, single and multi player as well! This is a 0 impact to performance datapack that fits into the lore of Minecraft, improving your gameplay experience!
